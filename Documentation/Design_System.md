# Design System

## Document Status

Draft Version 0.1

This document defines the initial design guidelines for the Global Work and Travel Ltd website.

The design system will guide UI consistency, branding, and future development.

---

# 1. Design Principles

The website design should communicate:

## Trust

Users should feel confident that the company is reliable.

## Professionalism

The interface should represent an international work and travel organization.

## Simplicity

Information should be easy to understand and navigate.

## Accessibility

The website should be usable across different devices and user abilities.

---

- Professional

- Supportive
